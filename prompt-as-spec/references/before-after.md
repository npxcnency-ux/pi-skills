# Before / After Prompt 对照

几组"差 prompt → 好 prompt"的对照，按原则归类。

---

## 案例 1：悬浮窗样式

### ❌ Before（模糊）
> 做一个录音时的悬浮窗，要好看，居中显示，里面有波形动画和文字。

**问题**：
- "好看"是噪声词
- 框架选型留白（NSWindow？NSPanel？SwiftUI Window？）
- 波形动画形态未定（圆点？竖条？曲线？）
- 文字怎么布局未定
- 居中是水平居中？屏幕中心？

### ✅ After（钉死）
> 录音时在屏幕底部居中显示无边框胶囊状悬浮窗。NSPanel(nonactivatingPanel) + NSVisualEffectView(.hudWindow)，高 56px、圆角 28px。左侧 5 根竖条波形 44×32px，右侧文字标签弹性宽度 160-560px。不要红绿灯、不要 titlebar。入场弹簧动画 0.35s。

**改进点**：
- 主观词翻译成数字（原则 2）
- 框架钉死（原则 1）
- 加反例约束（原则 3）

## 案例 2：文字注入

### ❌ Before
> 把转录的文字粘贴到当前输入框里。

**问题**：
- 实现方式未定（剪贴板？CGEventPost？AX API？）
- 跨输入法兼容性未提
- 剪贴板副作用未提

### ✅ After
> 使用剪贴板 + 模拟 Cmd+V 注入。注入前检测当前输入法：如果是 CJK 输入法，先切换到 ASCII 输入源（防止中文输入法拦截 Cmd+V），粘贴后恢复原输入法。注入完成后恢复原剪贴板内容。

**改进点**：
- 实现方式钉死（原则 1）
- 平台陷阱显式注入 + why（原则 4）
- 副作用复原（原则 5）
- 状态机完整（原则 6）

## 案例 3：LLM refine 子任务

### ❌ Before
> 用 LLM 优化一下转录文本，提升准确率。

**问题**：
- LLM 一定会"过度优化"——改写、润色、加标点、改语气
- 没有边界，LLM 自由发挥空间无穷大

### ✅ After
> 用 LLM 对转录文本 refine。System prompt 要求**非常保守**地纠错：只修复明显语音识别错误（如「配森」→「Python」、「杰森」→「JSON」）。**绝对不要改写、润色或删除**任何看起来正确的内容。如果输入看起来正确则**必须原样返回**。

**改进点**：
- 反例约束密集（原则 3）
- 具体例子注入领域知识（原则 4）
- 正例兜底"看起来正确就原样返回"，否则 LLM 觉得"不做事不专业"

## 案例 4：错误处理（兜底路径）

### ❌ Before
> 调用 LLM 优化文本。

**问题**：
- LLM 调用失败时？超时时？API key 没配？
- LLM 会随机加 try-catch / 兜底 / 退化

### ✅ After
> 调用 LLM 优化文本。失败路径：
> - API key 未配置 → 跳过 refine，直接注入原文本
> - 网络超时（>3s）→ 跳过 refine，直接注入原文本，菜单栏图标短暂变红
> - LLM 返回非法 / 空 → 同上
> 任何情况下**必须**保证原始转录文本能被注入。

**改进点**：
- 时序闭合（原则 6）
- 失败路径显式（不留给 LLM 猜）
- 用 MUST 锁兜底契约

## 案例 5：构建交付

### ❌ Before
> 用 Swift 写，能跑就行。

**问题**：
- 构建系统未定（Xcode project? SPM? Bazel?）
- 入口未定
- 产物形态未定（CLI? .app? framework?）
- 跑起来命令未定

### ✅ After
> macOS 14+，Swift Package Manager，LSUIElement 模式（仅菜单栏图标）。提供 Makefile，目标包含 build / run / install / clean。构建产物为签名的 .app bundle，安装到 /Applications。

**改进点**：
- 交付契约完整（原则 5）
- 入口、命令、产物路径全明确

| 维度 | ❌ Before | ✅ After |

| 尺寸 | "大一点" | "56px 高，28px 圆角" |

## 关键模式总结

写完一段需求后，扫一遍：

1. 这里有没有**主观词**？→ 翻译成数字
2. 这里 LLM **能选不同的实现路径**吗？→ 钉一个
3. 这里有**平台陷阱**吗？→ 显式点破 + 给 why
4. 这里 LLM **可能跑偏**吗？→ 加反例约束
5. 这里是**异步流程**吗？→ 列状态切换
6. 这里有**失败路径**吗？→ 显式兜底
